Money Manager
Design system & UI plan
Foundations Components Patterns Screens

A warmer, calmer way to see your money

This system keeps the density power users want — balances, due dates, portfolio detail — but wraps it in a softer palette, rounder shapes and encouraging copy, so daily check-ins feel supportive rather than clinical. Charts lead each dashboard, multi-currency and dark mode are first-class, and every screen defines what happens before there's data to show.
